## 二、已定案的 SP3 原則

- 首頁一眼看懂目前組別、角色、活動、進度、中斷狀態、下一步與真正需要
  注意的提醒。
- 少文字、少操作、不打擾，不顯示技術代碼或要求玩家判讀除錯資訊。
- 提醒卡最多三張，以組別彙整；斷線、恢復、時間及損失風險優先。
- UI 只能呈現 SP2 已確認的資料與決策，不能自行猜測或直接改寫領域狀態。
- 角色清單與詳細資料不外露穩定識別碼、視窗代碼、程序資訊或原始啟動參數。
- 角色備註可由玩家手動新增、修改與清除；保存成功後才刷新詳細資料。

## 三、允許的正式移入順序
