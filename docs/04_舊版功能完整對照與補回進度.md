# 輔｜舊版功能完整對照與補回進度

更新日期：2026-07-27（台灣時間）

## 固定原則

- 舊版程式與舊版設定只讀，不修改、不清除。
- 舊版已保存的組別、角色捷徑、視窗位置、大小與啟動間隔直接沿用。
- 只要舊版該組別已有位置設定，新版不得要求玩家重新設定。
- 新版新增或重新記錄的內容只保存到新版自己的設定。
- 無法唯一確認角色視窗或捷徑時停止操作，不猜測、不開重複視窗。

## 已存在於新版

- 組別選擇與目前組別保存。
- 角色捷徑加入與移除。
- 首頁角色狀態、單一角色切換與單一角色啟動。
- 鍵盤、滑鼠與連續點擊同步。
- 遞迴同步範圍、循環拒絕與衝突排序。
- 智慧重連、角色每日紀錄與日期／角色搜尋。
- 活動提醒卡、角色資料與備註。

## 本批補回

- 任一舊版已設定組別的一鍵整組啟動。
- 只補開尚未開啟的角色，不重複啟動已開啟角色。
- 啟動後依舊版保存內容還原每個角色的位置與大小。
- 沿用舊版各角色啟動間隔。
- 已開啟角色也可在同一次操作中還原位置。
- 只還原目前組別位置，不啟動缺少的角色視窗。
- 將目前組別全部已開啟角色的位置與大小一次記錄到新版設定。
- 組別新增、刪除、改名、上移與下移。
- 指定主窗口與清空目前組別角色；清空前必須再次確認。
- 所有主內容頁共用垂直滾動；視窗縮小時仍能向下查看完整內容。
- 俐落藍、柔和紫、舊版金色與極簡黑白目前只作介面比較稿；使用者尚未
  確認最終介面，不得標成定案。
- 背景圖片由使用者自行選擇與更換，並支援任何圖片格式，包含相機原始檔
  （例如 CR2）；程式自動辨識及轉成可顯示副本，原檔保持不變。非圖片不在
  此範圍；解碼失敗時要明確提示並保留原背景，不得無反應。
- 背景圖片保持原比例完整顯示並置中，不裁切、不拉伸；圖片未覆蓋區域使用
  可在「設定」調整的填補色；預設值以使用者最新提供的舊版截圖既有主背景色
  為準，不另行創造新版顏色。
- 圖片小於程式可用背景區域時，保持原始像素尺寸置中，不放大、不補點、不
  改變解析度。
- 圖片大於程式可用背景區域時，保持原比例等比例縮小至可完整顯示的最大尺寸
  並置中，不裁切、不拉伸。
- 每次設定背景圖片時，同時選擇套用範圍：全部頁面或指定功能頁面；不得固定
  成只能全程共用或只能每頁分開設定。
- 背景圖片在指定頁面內涵蓋整個程式內容區，包含左側選單與右側操作區；
  選單及操作元件覆蓋在圖片上，不限於右側內容區。
- 左側選單、操作面板與角色列使用半透明舊版配色，讓背景可從元件後方透出；
  不採完全不透明；透明程度可在「設定」內自行調整，不固定成單一值。
- 透明度採全程共用設定：所有背景圖片與所有套用頁面共用同一個透明度，
  不為每張背景圖片分別保存透明度。
- 左側選單、操作面板與角色列的透明度分開設定，三個區域各自保存透明度；
  不共用同一個透明度數值。
- 同一頁面再次設定另一張背景圖片時，新圖片直接取代該頁原本的背景圖片；
  同一頁面不保留多張背景供切換。

## 下一批依舊版操作方式補回

- 組別設定匯入與匯出。
- 主窗口鎖定、切換與批次加入。
- 個別同步視窗偏移、延遲、角色身分校正及主基準點。
- 自訂同步按鍵與整組啟動快捷鍵。
- 遊戲時間校正與自動更新。
- 定時按下。
- 斷線偵測的小狀態視窗。
- 還原／調整遊戲視窗尺寸。
- 系統匣與小型狀態入口。

## 不直接照搬的舊版部分

- 原始登入參數、登入權杖與程序命令列不搬移、不顯示。
- 會與目前已確認安全規則衝突的舊操作，改用新版失敗關閉規則。
- 舊版區塊展開／收合改由左側頁面與全頁滾動承接，不讓內容因視窗大小被截斷。

## 已確認的匯入覆蓋規則

- 匯入設定遇到同名組別時，直接覆蓋新版自有設定中的同名組別。
- 不建立第二個同名組別，不自動加尾碼或另建副本。
- 舊版來源設定檔保持只讀；被覆蓋的是新版自己的設定副本。
