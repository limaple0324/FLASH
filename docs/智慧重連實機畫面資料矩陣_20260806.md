## 使用規則

- 固定來源為第 35 號合併請求最新提交 `7f9de1812a66b5297bbe9f21f14e209ec31dd673` 目前已有的使用者圖片、來源雜湊及不可還原證據。
- 下表的「可操作」只表示該畫面在完整前置狀態、兩張新鮮相同證據及點前完整身分重驗都成立時的唯一操作；單張圖片永遠不授權操作。
- 所有既有辨識基準均標為「不得作正式通過證據」；正式通過證據必須來自固定提交執行時另行產生的匿名實機紀錄。
- 原圖沒有記錄前景、遮擋或縮小狀態時一律標示「未記錄」，不得事後推測。

## 尚缺的真實反例

1. 同一固定提交下，斷線流程各階段的真實錯位、局部載入、未知彈窗及舊畫面樣本。
2. 同一視窗分別在縮小、部分遮擋、完全遮擋、遊戲視窗互相重疊及其他程式位於前景時的完整斷線生命週期。
3. 同等級多角色、原線路需捲動、登入逾時及多視窗同時斷線的完整匿名實機紀錄。
4. 上述反例未由程式自動留下以前，不能用人工調亮、縮放、拼貼或測試假結果替代。
