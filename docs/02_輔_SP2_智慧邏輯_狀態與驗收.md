## 三、已完成的 SP2 核心

### 角色、組別與全域優先序

- 角色、組別、等級、定位、重要程度及備註資料模型。
- 角色資料與組別的安全保存、載入及唯讀玩家快照。
- 全專案角色預設優先序集中為：
  `主號 → 次要（分號／小號）→ 備用`。
- 同一身分層才比較較高等級，再以穩定識別維持可重現順序。
- 角色清單、詳細資料、決策服務與智慧重連使用同一中央排序，不再各自猜測。

### 活動、進度與午夜重置

- 活動定義、每日／週期型別、進度、開始、完成次數及台灣時間每日
  `00:00` 重置。
- 活動進度採受管理資料目錄與原子保存；損壞時保留安全失敗狀態。
- 未確認完成條件的活動不會被自行標成完成、失敗或略過。

### 工作區與提醒卡資料

- 目前組別、目前活動、下一步與可信狀態的工作區模型。
- 以組別彙整的提醒卡資料、三張上限、優先原因、生命週期與顯示時間設定。
- 卡片歷史、重複卡更新、到期清除及唯讀 `View State`。
- SP3 首頁與右下角浮層只讀取 SP2 已提供的可信狀態，不在畫面層猜測。

### 決策與玩家習慣

- 決策服務輸出固定為「提醒／建議／保持安靜」。
- 未知證據、玩家取消、無新資訊、重複提醒及不適合打擾時會保持安靜。
- 活動順序習慣先觀察七個有效日，第八天才提供玩家檢視。
- 例外日不列入門檻；玩家可接受、修改、暫停、恢復、取消檢視或全部清除。
- 習慣只影響建議與排序，不會直接產生遊戲輸入。

### 可信視窗與恢復邊界

- SP1 目標視窗觀察可轉成不含視窗代碼、像素、程序資訊及原始參數的 SP2
  唯讀狀態。
- 已確認的斷線、登入首頁、選線、選角、正常遊戲、公告／玩法推薦、
  日常活動及自動副本畫面由 SP1 智慧重連流程辨識。
- 未知畫面、視窗數不完整、缺少角色規則或未由玩家明確啟用時不點擊。

## 五、安全規則

- 鍵盤同步與智慧重連每次程式啟動一律為安全停止。
- 只有本次執行中由玩家明確啟用，才可能送出已確認輸入或點擊。
- ESC 只是遊戲操作，不會被「輔」或 Codex 當成停止開發／監看指令。
- 只有玩家文字或語音明確說「停止／暫停」才停止工作。
- 所有多角色選擇、排序、登入、執行、提醒、等待或略過，預設都遵守
  `主號 → 次要（分號／小號）→ 備用`。
- 安全、斷線、硬性時限及立即損失風險可先於角色層級；進入同一層後仍套用
  角色優先序。
- 不顯示登入參數、原始捷徑路徑、視窗代碼、程序資訊或穩定內部識別碼。

## 七、仍待補充，因此不得自行實作

以下不是「忘記做」，而是缺少正式規則或真實畫面證據：

1. 除神秘考官、世界 BOSS、魔兵外，各活動的精確參與角色範圍。
2. 各定時活動的提醒提前量、最晚進場時間及活動結束時間。
3. 各活動實際地圖名稱，以及進場、活動結束或領獎何時才算完成。
4. 跨組同步的遞迴範圍、重複路徑、循環、相同／不同操作衝突及重連期間補做
   規則已定案；相關結果納入角色每日紀錄，不顯示於主畫面。
5. 程式內紀錄區的即時內容只保留最近一個月；每一日期一個文字記錄檔，同日
   持續追加且不覆蓋，跨日才建立新檔。每日檔案分角色保存「輔」當日執行、
   偵測或處理的所有相關事情與結果，先依角色分區，再在各區內依時間排列。
   所有已設定角色固定保留區段，當日無操作時區段留白。紀錄區支援依日期與
   角色搜尋，搜尋結果可直接開啟對應每日檔案。
6. 角色重連等待期間即使被移出同步組，先前已保留的操作仍須在重連成功且能
   唯一確認角色後補做並留下紀錄；使用者在等待期間關閉同步亦不取消補做。
   「輔」被關閉或重新啟動時也須安全保存，重啟後確認重連成功且能唯一確認
   角色時，依原順序補做並留下紀錄。保留操作不設最長等待期限；每次補做前
   必須重新核對目前遊戲畫面，不適合時略過該操作並記錄。略過
   一項後，該角色後面的所有保留操作全部停止、不再逐一檢查並全部寫入紀錄；
   這些後續操作永久取消，不在之後補做。仍待確認其他角色的保留操作是否照常
   各自補做。
7. 十四個視窗同步時，只要一個角色斷線，其餘角色立即停止執行新的同步操作，
   所有新操作依原順序暫停保留，只處理斷線角色的安全重連。成功重連、唯一
   確認且完成安全畫面確認後，再依原順序補做全部暫停操作。重連失敗時先
   記錄，隨即只用該角色原捷徑執行重開視窗流程，其他角色與視窗完全不動，
   十四視窗同步繼續暫停。重開仍失敗時立即再次只重開該角色，不等待六十秒，
   每次失敗與重開都留下紀錄。此規則優先於固定等待重試；仍待確認連續立即
   重開是否需要停止條件。
8. 玩家可見視窗登記頁的內容、分類、判定與文案。

上述項目在使用者補充前維持失敗關閉，不用猜測填空。
