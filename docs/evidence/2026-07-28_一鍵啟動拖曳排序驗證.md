# 一鍵啟動拖曳排序驗證

日期：2026-07-28

## 完成範圍

- 目前組別頁提供「調整順序」模式。
- 拖曳期間只預覽；按「完成排序」才原子保存，按「取消」不保存。
- 預設確認組別仍沿用既有 1～14 固定順序。
- 玩家保存自訂順序後，一鍵啟動依保存順序執行。
- 各角色啟動延遲仍使用該角色既有保存值。
- 排序只改啟動順序，不改主窗口身分。
- 同步主控依角色欄位確認，不再把排序後第一列誤當主控。
- 重啟後可還原自訂順序。
