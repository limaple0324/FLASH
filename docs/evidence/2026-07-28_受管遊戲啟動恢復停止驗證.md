# 受管遊戲啟動、恢復與停止驗證

日期：2026-07-28

## 完成範圍

- 沿用已驗證的一鍵啟動、保存順序、角色延遲與位置排列核心。
- 「恢復上次位置」只還原目前組別已保存的位置與大小，不啟動缺少的視窗。
- 啟動、恢復及記錄位置時，保存可唯一確認的視窗代號、程序代號與匿名身分。
- 受管程序紀錄原子保存；損壞時保留原檔並停止所有關閉操作。
- 「停止全部受管遊戲」先停止鍵盤滑鼠同步、連續點擊、定時操作與智慧重連，
  再等待整組啟動停止，最後才正常關閉受管視窗。
- 只關閉視窗代號、程序代號及匿名身分全部一致的視窗。
- 未知、重複、身分改變、非目標或關閉失敗的視窗保持不動。
- 所有失敗使用中文狀態並寫入既有紀錄區。
