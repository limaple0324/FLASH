# 2026-07-28 自訂快捷鍵與輸入同步驗證

## 完成範圍

- 功能啟閉與整組啟動共用同一套 Windows 按鍵正規化。
- 支援標準鍵盤、滑鼠左／右／中／側鍵、空白鍵、方向鍵、功能鍵、
  數字鍵盤、媒體鍵及 Windows 可辨識的其他虛擬鍵。
- 上排數字鍵與右側數字鍵盤分開辨識、保存及重啟恢復。
- 玩家從主窗口操作滑鼠左鍵時，不重送主窗口，只向其他合格視窗各送一次。
- 非主控角色不得發起鍵盤或滑鼠同步。
- 遞迴跨組範圍依角色唯一身分去重；既有保存前循環拒絕規則保持有效。
- 鍵盤與滑鼠每送下一個視窗前重新檢查停止狀態。

## 整批驗證

- 快捷鍵、組別保存、鍵盤監看、滑鼠監看、鍵盤送出、滑鼠送出、
  同步範圍、衝突仲裁及主程式接線受影響測試：119 項全部通過。
- 驗證時間：1.79 秒。
- 已驗證 14 視窗時，主窗口只保留玩家原始操作，其他 13 個視窗各收到一次。
- 已驗證停止發生後，尚未處理的下一個視窗不再收到輸入。

## 尚待最終實機

- 真實 Flash 14 視窗的遊戲接收延遲、誤差與長時間穩定性，仍依總指令留到
  Windows 11 完整回歸，不以模組測試冒充實機完成。
