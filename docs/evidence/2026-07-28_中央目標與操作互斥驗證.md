# 中央目標、跨組綁定與操作互斥驗證

日期：2026-07-28

## 驗證範圍

- 偵測、首頁狀態、鍵盤同步、滑鼠同步、智慧重連及前台操作共用中央目標快照。
- 目前組別的角色與視窗資料優先；跨組共用捷徑不沿用上一組角色資料。
- 切組先關閉操作閘門並等待進行中操作結束；失敗時回復原組別資料及閘門狀態。
- 鍵盤、滑鼠、延遲補做、智慧重連、連續點擊、定時點擊、單一角色啟動及整組視窗操作共用互斥閘門。
- 未識別、重複或無法唯一確認的遊戲視窗保持不操作。

## 必要相依修改

- `services/group_character_registration_service.py`：避免共用捷徑因切組而改寫既有角色歸屬。
- `services/group_selection_service.py`：避免跨組共用捷徑帶入上一組角色識別。
- `services/auto_click_service.py`、`services/game_time_timed_click_service.py`：納入所有會改變遊戲狀態的操作互斥。

上述修改只處理本批中央身分與操作互斥，不改變已驗收的快捷鍵種類、介面或智慧重連畫面流程。
