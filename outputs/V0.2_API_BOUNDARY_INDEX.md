## API 範圍

- `GroupAPI`：組別新增、刪除、改名、排序、切換、刷新目前組別 UI。
- `LaunchAPI`：整理本組、補開缺少視窗、記錄位置、綁定啟動清單視窗。
- `MainWindowAPI`：設定主窗口、主窗口上鎖 / 解鎖、主窗口顯示文字。
- `SyncAPI`：開始同步、停止同步、同步狀態、滑鼠 / 鍵盤 / 滾輪同步。
- `HotkeyAPI`：同步快捷鍵、整理鍵、快捷鍵衝突清除、快捷鍵輪詢。
- `CharacterAPI`：角色 ID 讀取、校正、模板比對、檔名備援相關範圍。
- `MonitorAPI`：斷線偵測、目前組別掃描、偵測結果顯示。
- `TrayAPI`：系統匣、X 收回、喚醒、右鍵選單、關閉程式。
- `StatusWindowAPI`：小狀態窗、多組顯示、拖曳、縮放、整理 / 關閉按鈕。
- `SettingsAPI`：AppData 設定、V0.2 備份設定檔、匯入 / 匯出。
- `DpiWindowAPI`：DPI、雙螢幕、主程式位置與大小穩定邏輯。

## 保護原則

後續改動只處理使用者指定的 API 範圍。未列在變更清單的 API 不修改。

禁止在未指定情況下進行：

- 大搬動主程式結構。
- 把單檔拆成多檔。
- 重寫組別管理。
- 重寫主窗口判定。
- 重寫系統匣邏輯。
- 重寫 DPI / 雙螢幕邏輯。
- 改變快捷鍵重複清空規則。
- 改變 X 收回系統列行為。

```powershell
python verify_v02_api_boundaries.py
```

檢查項目：

- `MODULE_API_METHOD_INDEX_V02` 是否包含固定 11 個 API。
- `PROTECTED_API_BOUNDARIES_V02` 是否與固定 API 清單一致。
- API 索引內的方法名稱是否能對上現有函式或 class method。

- V0.1 是否仍是 `輔V0.1`，避免誤動穩定版。
