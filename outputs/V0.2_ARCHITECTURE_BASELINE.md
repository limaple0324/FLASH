# 輔V0.2 架構整理基準

版本：V.02 / v0.2

這份文件是輔V0.2的架構整理基準。輔V0.1保留為穩定完成品，不覆蓋、不作為實驗版本。V0.2所有調整都必須先確認對應 API，再針對該 API 小範圍處理。

## 版本隔離

- V0.1 穩定版：`輔V0.1.exe`、`flash_sync.py`。
- V0.2 架構版：`輔V0.2.exe`、`flash_sync_v02.py`。
- V0.2 不覆蓋 V0.1 exe。
- V0.2 使用獨立 AppData 設定資料夾：`%APPDATA%\輔V0.2`。
- V0.1 原本設定資料夾保留：`%APPDATA%\同步器`。
- V0.2 設定備份固定使用：`%APPDATA%\輔V0.2\sync_launch_config_v02.json`。
- V0.1 outputs 設定備份保留：`sync_launch_config.json`。
- V0.2 不在桌面或 exe 所在資料夾自動產生設定備份。
- 若 V0.2 發生問題，直接退回使用 V0.1。

## V0.2 目標

1. 逐步建立模組/API 邊界。
2. 建立統一事件與設定管理方向。
3. 不一次性大拆 30 萬字元單檔。
4. 不重寫已驗證穩定功能。
5. 每次只針對指定 API 做小範圍調整。

## V0.2 穩定 API 邊界

### GroupAPI

負責：組別新增、刪除、改名、排序、取得目前組別。

### LaunchAPI

負責：整理本組、恢復位置、補開缺少視窗、啟動檔身份配對。

### MainWindowAPI

負責：設定主窗、上鎖、解鎖、取得主窗。

### SyncAPI

負責：開始同步、停止同步、同步狀態、同步事件。

### HotkeyAPI

負責：快捷鍵設定、清除、重複衝突處理。

### CharacterAPI

負責：讀取角色 ID、校正角色 ID、檔名備援、跨組身份。

### MonitorAPI

負責：斷線偵測、掃描狀態、常駐偵測名單。

### TrayAPI

負責：系統匣、喚醒、關閉、X 收回。

### StatusWindowAPI

負責：小狀態窗、多組顯示、拖曳、快速整理。

### SettingsAPI

負責：AppData 設定、outputs 備份、machine id、版本設定隔離。
