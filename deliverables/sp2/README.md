# 輔｜SP2 獨立交付區域

此目錄是 SP2 自己的來源範圍、測試、成品與驗收入口。它不複製另一套
SP1 原始碼，也不把 SP1＋SP2 累積程式誤標成「SP2 單獨執行檔」。

## 目前身分

- 工作區：`C:\Users\USER\Documents\輔\SP2`
- 分支：`sp2/completion-2026-07-26`
- SP1 基底：`64ecfc23eb55b819058fc88f481a09cb0bbbc913`
- 既有整合成果來源：`integration/sp2-sp3-sp35@bd685fbfd346de6cec32d9bbfc2184571dbf4ab0`
- 累積程式身分：SP1＋SP2
- SP2 獨立交付身分：本目錄、SP2 狀態文件、來源範圍清單、測試與成品證據

## 固定範圍

本階段只移入與完成已討論清楚的 SP2 Brain：

- 產品原則
- 角色、組別、活動、三態與進度
- 台灣時間每日重置與安全保存
- 工作區狀態與服務
- 組別級提醒卡資料、優先原因、生命週期與必要歷史
- 後續已確認的決策、習慣及跨組同步邏輯

以下維持暫停，不移入、不新增、不延伸：

- 魂器
- 寵物天賦
- 黑曜石
- 命魂
- 背包
- 玩家可見視窗登記頁的欄位、分類、判定、文案與大量角色版面
- 需求第 3、8 項尚未確認的精確內容

SP3 的首頁、浮層、角色視窗與陪伴呈現也不在 SP2 階段新增。

## 交付方式

- 可執行程式由同一套 SP1＋SP2 累積原始碼建立。
- 本目錄只保存 SP2 新增範圍與證據，避免多套原始碼互相漂移。
- SP1 獨立成品保留在 `C:\Users\USER\Documents\輔\SP1成品`，不得覆蓋。
- SP2 完成後會建立獨立 SP2 證據包與 SP1＋SP2 累積 Windows 成品。
- 到 SP3 階段另保留 SP3 獨立交付，並建立 SP1＋SP2＋SP3 完整整合成品。
