## 本階段允許移入

- 玩家首頁及可信唯讀狀態中文呈現。
- 提醒卡內容、右下角浮層與玩家可調顯示時間。
- 角色清單、角色詳細資料及備註編輯畫面。
- 由 SP2 View State／服務提供資料的正常主流程接線。

## 本階段禁止移入

- 命魂編輯與任何命魂欄位。
- 未經使用者確認的「靈魂石」名稱與舊資料流程。
- 魂器、寵物天賦、黑曜石與背包。
- 尚未定案的玩家可見視窗登記頁。
- UI 自行讀取遊戲畫面、猜測完成狀態或直接產生未授權輸入。
- 舊整合分支整包合併或覆蓋目前 SP1／SP2。
