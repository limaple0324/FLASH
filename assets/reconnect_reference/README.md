# SP1 斷線重連畫面基準

本目錄保存使用者於 2026-07-25 提供的完整單一 Flash 視窗原圖。來源已由
Codex 暫存路徑移入專案，避免重新開機或暫存清理後遺失。
原檔 SHA-256 固定保存在 `SHA256SUMS.txt`，測試會逐一核對。

已確認流程：

1. `01_disconnected_dialog.png`：遊戲中斷線，按中央「確定」。
2. `02_login_start_screen.png`：回到登入起始畫面。一般首次進入按「開始遊戲」；
   剛從斷線流程回來則必須按「強制登入」。
3. `03_line_selection_dialog.png`：線路清單。
4. `04_default_top_line_button.png`：早期最上方線路的局部歷史參考；目前不作
   預設點擊，實際動作一定依最近登入線路編號決定。
5. `05_character_selection.png`：角色選擇畫面，按「進入遊戲」。
6. `06_connected_gameplay.png`：正常連線的遊戲畫面。
7. `07_post_login_activity_popup.png`：登入後「日常活動／活躍度」視窗，按右上
   `X`。
8. `08_post_login_recommendation_popup.png`：登入後「玩法推薦」視窗，按右上
   `X`。
9. `09_force_login_progress.png`：按下「強制登入」後的進度畫面；不點擊，
   約等待 10 秒後才會進入線路選擇。
10. `10_route_digit_7.png`、`11_route_digit_8.png`：只保留最近登入線路的
    數字像素，不含角色名稱，用於動態選線。
11. `12_post_login_auto_dungeon_popup.png`：登入後「自動副本」視窗，按該
    視窗自己的右上 `X`；這是使用者後續補充確認的第三種登入後視窗。
12. `character_level_100.png`、`character_level_120.png`、
    `character_level_160.png`：只保留角色等級文字的最小參考，不含名稱。

角色選擇畫面不得固定選最左邊。辨識先套用全專案角色身分優先序
「主號 → 次要（分號／小號）→ 備用」，同層再選最高等級；若目前選取
的不是目標角色，先選角色，下一輪確認後才按「進入遊戲」。未知等級或
不可靠畫面維持不點擊。

選線規格：

- 先讀取「最近一次登入資訊」的線路編號，再選對應清單項目。
- 1 → 麻布老虎1線；2 → 公會專線；3～7 → 麻布老虎3～7線；
  8 → 新奇拍賣專線。
- 目前可信數字模板只有使用者實際提供的 7 與 8；遇到 1～6 時先停在選線
  畫面，不沿用舊的固定最上方點法，取得該數字原圖後再啟用。
- 最近登入狀態整行會因角色名稱長短而左右移動；辨識先找固定「線路：」
  前綴，再擷取其後數字，因此不依賴固定水平座標。

安全規則：

- 所有動作使用 Flash 客戶區相對座標，不使用桌面絕對座標。
- 每批操作先驗證預期 14 個視窗、14 個不同程序及 14 個不同匿名啟動指紋。
- 未辨識畫面不得猜測或點擊。
- 同一視窗停留在同一可操作畫面時不重複點擊；畫面改變後才立即進入下一步，
  若一直不變則滿 60 秒才重試同一動作。
- 斷線流程、公告關閉資格與重試截止時間只以匿名啟動指紋保存；程式重啟後
  延續，不保存視窗代碼、程序代號、角色名稱、原始參數或畫面。
- 三種登入後視窗只在控制器自己啟動的登入／重連流程內關閉；玩家平常手動
  打開相同視窗時只辨識，不點擊。
- 若遊戲另有未提供的純載入或重連失敗版型，先保持觀察並依規則每 60 秒
  重試；收到新原圖後才新增可操作模板。
- 原圖只作辨識基準，不寫入執行紀錄或驗證報告。
