## 共通安全規則

- 只保存實際開啟且可靠讀到的頁面；未讀頁不得清除。
- 只有內容改變才更新，資料綁定可靠的實際角色身分。
- 目前只做唯讀紀錄，不切頁、不點亮、不送鍵盤或滑鼠輸入。
- 不完整、被遮擋或無法唯一確認的畫面必須保留為未知，不可猜測。
