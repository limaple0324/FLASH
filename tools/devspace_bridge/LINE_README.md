# LINE 安全橋接（第一階段）

這一版的目的只有三件事：

1. 從 LINE 查詢本機橋接、遊戲程序與視窗狀態。
2. 提供 LINE 通知能力，讓其他已驗證模組日後可以安全呼叫。
3. 先建立遠端控制入口，但任何會操作遊戲的重連／莊園命令目前一律鎖定。

不修改智慧重連流程，不修改莊園流程，也不提供任意終端命令、任意檔案操作或任意程序控制。

## 第一次設定

雙擊 `設定LINE橋接.cmd`。

需要從 LINE Developers（LINE 開發者後台）的 Messaging API（訊息介面）頻道取得兩個值：

- 頻道密鑰
- 頻道存取權杖

請只貼到本機設定視窗，不要貼進聊天、GitHub 或程式碼。Windows 上會使用 DPAPI（Windows 資料保護介面）加密後保存於目前 Windows 使用者的本機資料夾。

接著按「安裝對外連線元件」。程式只下載固定版本的 `cloudflared`（Cloudflare 對外通道元件）2026.8.3，並驗證 SHA-256（雜湊）為：

`83e726ed18ea78c5ad5213c4c3a3a27051393950d2bc8ed4de69bec12d14eaae`

驗證不符就拒絕安裝。

## 啟動與初次配對

雙擊 `啟動LINE橋接.cmd`。

橋接只監聽本機 `127.0.0.1:8787`，再由對外通道提供 HTTPS（加密網頁連線）網址。每次啟動會自動把目前網址寫到 LINE 的 Webhook（事件回傳）設定並執行測試。

LINE Developers（LINE 開發者後台）中的 `Use webhook`（使用事件回傳）仍需要人工開啟一次；這是 LINE 頻道本身的開關。

第一次啟動且尚未有授權帳號時，設定視窗會顯示 6 位數配對碼。用自己的 LINE 對官方帳號傳送：

`配對 123456`

配對碼 15 分鐘有效；配對成功後，只接受該一對一使用者來源。群組與聊天室來源第一階段直接忽略。

## 現在可用的 LINE 指令

- `狀態`：本機 Devspace 橋接是否存在、可觀察遊戲程序數、可觀察視窗數、遠端控制鎖定狀態。
- `視窗`：列出可觀察遊戲視窗標題與程序編號。
- `重連狀態`：唯讀 `%LOCALAPPDATA%\輔\Devspace\status\smart_reconnect.json`；沒有快照就明確回覆沒有資料。
- `莊園狀態`：唯讀 `%LOCALAPPDATA%\輔\Devspace\status\manor.json`；沒有快照就明確回覆沒有資料。
- `幫助`／`指令`／`功能`：顯示允許指令。

以下命令雖然已有入口，但目前一定回覆「安全鎖定」，不執行遊戲操作：

- `重連`
- `強制重連`
- `執行重連`
- `莊園`
- `執行莊園`
- `莊園執行`
- `停止莊園`

未知文字同樣拒絕，不會被轉成 PowerShell（Windows 指令殼層）、CMD（命令提示字元）或其他系統命令。

## 通知入口

完成配對後，可由本機受控程式呼叫：

`python -m tools.devspace_bridge.line_bridge_main --push "通知內容"`

這只會把文字推送給已配對使用者。第一階段沒有把尚未穩定的智慧重連／莊園流程直接掛上自動通知，以免擴大兩個核心流程的故障面。

## 安全邊界

- LINE Webhook（事件回傳）先驗證原始請求簽章，驗證失敗直接拒絕。
- 只接受固定白名單文字指令。
- 重複事件會去重，避免同一事件執行兩次。
- 密鑰不寫入 GitHub。
- 不提供任意系統命令。
- 遊戲控制命令第一階段硬鎖。
- `停止LINE橋接.cmd` 只建立停止請求，由橋接程式自行退出，不會強制終止其他程序。

目前使用的 Cloudflare Quick Tunnel（Cloudflare 快速通道）適合測試與初期使用；日後若要長期 24 小時運作，再換成固定名稱的通道，不需要重做 LINE 指令層。
